## 2026-07-02 - Trilingual UX Localization and Flow
**Learning:** Localizing system feedback (waiting, errors, disclaimers) is essential for a consistent trilingual experience in multilingual bots; additionally, editing existing status messages instead of sending new ones significantly reduces chat noise and makes the interface feel more responsive ("snappy").
**Action:** Always ensure system-generated messages respect the user's selected language and utilize message editing for transitory states like "Waiting...".
