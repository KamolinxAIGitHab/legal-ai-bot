## 2025-05-15 - Multi-lingual UX Localization in Telegram Bots
**Learning:** In multi-lingual bots, keeping system feedback (waiting, errors, success) in the user's selected language significantly improves perceived quality and trust. Editing status messages instead of sending new ones reduces chat noise and makes the interface feel "snappier".
**Action:** Always implement a central localization mapping for system strings and use message editing for progress updates.
