## 2026-06-18 - Localized UX and Message Management in Telegram Bots
**Learning:** Localizing system feedback (waiting, errors, disclaimers) and the initial trilingual prompt significantly improves accessibility for multilingual audiences. Additionally, editing existing status messages instead of sending new ones reduces chat noise and makes the bot feel more responsive.
**Action:** Always include localization for system messages and prefer editing status messages for AI processing feedback.
