## 2025-05-24 - Localized System Feedback
**Learning:** In multi-lingual bots, hardcoded system messages in a single language (like "Waiting...") create a jarring UX for users who selected a different interface language. Localizing these "non-core" strings is essential for a cohesive experience.
**Action:** Always use a localization mapping for system status and error messages, and provide visual feedback (like 'typing' actions) to maintain engagement during async operations.
