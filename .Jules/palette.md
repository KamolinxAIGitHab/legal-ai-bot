## 2025-05-14 - [Multilingual UX & State Feedback]
**Learning:** Localizing all system messages (waiting, errors, disclaimers) and providing immediate visual feedback via `typing` chat actions significantly improves perceived responsiveness and accessibility for multilingual users. Replacing "waiting" placeholders with final answers using `edit_text` reduces chat clutter and maintains focus.
**Action:** Always implement a centralized localization map and use message editing for asynchronous AI responses in Telegram bots to ensure a clean, accessible interaction flow.
